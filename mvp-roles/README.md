# MVP — app de rolês

App web mobile-first para organizar rolês, resenhas e festas pequenas em São Paulo: convite com link, lista com aprovação,
cobrança por Pix, quem leva o quê, calculadora anti-prejuízo e check-in por QR na porta.

**Status:** Fase 0 (planejamento) concluída, aguardando aprovação. Ainda não há código de produto.
